# GraphMotorcycle — ระบบเช่าและแนะนำรถ

## รันระบบ
```bash
pip install -r requirements.txt
streamlit run app.py
```
คัดลอก .streamlit/secrets.toml.example เป็น .streamlit/secrets.toml ใส่ URI, username, password ของฐานข้อมูล และ database="neo4j" อย่าเผยแพร่รหัสผ่าน

เปิด จัดการข้อมูล / รูปภาพ → สร้างข้อมูลตัวอย่าง ระบบสร้าง User 10 คน Motorcycle 10 รุ่นพร้อมภาพ และ RENTED จำลอง 21 รายการจากคู่ LIKES ต้นทาง วันที่ตัวอย่าง 1–2 กันยายน 2026 สถานะ returned และ is_demo=true ไม่ใช่การเช่าจริงใน Notebook กดสร้างซ้ำไม่เพิ่มประวัติจำลองซ้ำ ไม่ลบข้อมูลเดิม

เมนู: ภาพรวมระบบ, รถแนะนำสำหรับคุณ, ค้นหารถเช่า, เช่ารถ / ให้คะแนน, กราฟการเช่ารถ, จัดการข้อมูล / รูปภาพ

บันทึกเช่าเลือกวันเริ่มและวันคืน (วันคืนต้องไม่ก่อนวันเริ่ม) แต่ละครั้งสร้าง RENTED ใหม่พร้อม rental_id และสถานะ active คืนรถปรับเป็น returned และให้คะแนน 1–5 ได้ ข้อมูลเก็บใน Neo4j

คำแนะนำใช้ประวัติ RENTED ตัดรถที่เคยเช่าแล้ว นับเส้นทาง shared model / other user / recommended model ที่ไม่ซ้ำ การเช่ารุ่นเดิมหลายครั้งไม่ทำให้คะแนนเพิ่มซ้ำ คะแนนดาวใช้แสดงประวัติ ไม่ได้รวมในคะแนนแนะนำ Mint ได้ Vespa Primavera 2 คะแนน Kawasaki Ninja 400 และ Suzuki GSX-R150 อย่างละ 1 คะแนน

ระบบนี้บันทึกประวัติการเช่าตามรุ่นรถเพื่อโครงงาน ไม่มีทะเบียนรถรายคัน จำนวนรถว่าง การจองช่วงเวลาที่ชนกัน ค่าเช่า หรือการชำระเงิน

Notebook ในแพ็กเกจเป็นข้อมูลความชอบต้นทาง ส่วนเว็บใช้ RENTED สำหรับการเช่า
