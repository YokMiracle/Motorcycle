# ระบบแนะนำรถจากประวัติการเช่าและคะแนน

รัน pip install -r requirements.txt แล้ว streamlit run app.py
คัดลอก .streamlit/secrets.toml.example เป็น secrets.toml และกรอกข้อมูล Neo4j ของคุณ

เมนู ประวัติการเช่า / ให้คะแนน ใช้บันทึกหลังเคยเช่ารถแล้ว: ผู้ใช้ รุ่นรถ วันที่เคยเช่า และคะแนนความพึงพอใจ 1–5 ไม่มีการจอง วันกำหนดคืน หรือขั้นตอนคืนรถ

เปิด จัดการข้อมูล / รูปภาพ → สร้างข้อมูลตัวอย่าง เพื่อเพิ่ม User 10 คน Motorcycle 10 รุ่น และประวัติ RENTED พร้อมคะแนนจำลอง 21 รายการ คู่ผู้ใช้/รถมาจากความชอบใน Notebook ต้นทาง ส่วนวันที่ 1–21 กันยายน 2026 และคะแนน 4.5,4,5,3.5 วนตามลำดับเป็นข้อมูลจำลอง ไม่ใช่คะแนนจริง ใช้ is_demo=true ระบุ กดซ้ำไม่เพิ่มตัวอย่างซ้ำ หากใช้เวอร์ชันเช่าก่อนหน้า ปุ่มนี้เติมคะแนนให้ประวัติ demo เดิม ไม่ลบประวัติจริง

คะแนนแนะนำ = จำนวนเส้นทางความคล้ายที่ไม่ซ้ำ × 3 + คะแนนรีวิวเฉลี่ยของรถ × 0.5 เส้นทางคือ ผู้ใช้ → รถที่เคยเช่า → ผู้ใช้อื่น → รถรุ่นใหม่ ตัดรถที่ผู้ใช้เคยเช่าแล้ว เช่ารุ่นเดิมซ้ำไม่เพิ่มเส้นทางซ้ำ คะแนนเฉลี่ยคิดจากรายการที่มีคะแนนทุกครั้ง ระบบอธิบายคนที่มีประสบการณ์คล้ายกันและแสดงภาพรถ คะแนนดาว และคะแนนแนะนำแยกกัน

ประวัติเดิมที่ไม่มีคะแนนยังแสดงได้ แต่ไม่รวมในค่าเฉลี่ย รีวิวใหม่เก็บใน Neo4j และมี is_demo=false Notebook เป็นข้อมูลความชอบต้นทาง ใช้ศึกษาที่มาของคู่ผู้ใช้/รถ ไม่ใช่ระบบรีวิวใหม่
