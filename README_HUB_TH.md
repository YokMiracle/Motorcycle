# หน้ารวมโปรเจกต์มอเตอร์ไซค์

ปรับจากไฟล์ Motorcycle(7).zip ให้หน้าแรกเป็นหน้ารวม 3 การ์ดแบบตัวอย่าง Anime Recommendation Hub ในโทนชมพูพาสเทล

- โครงสร้างข้อมูล: ไฟล์แรก Python / NetworkX
- วิเคราะห์ความสัมพันธ์: ไฟล์ที่สอง Neo4j / LIKES
- ระบบแนะนำ: เปิดระบบเดิมภายในแอปนี้ พร้อมปุ่มกลับหน้ารวม

ไฟล์โน้ตบุ๊กแนบสองไฟล์คัดลอกโดยไม่แก้โค้ดหรือข้อมูล อยู่ใน notebooks/
หน้ารวมเปิดได้โดยไม่ต้องเชื่อมต่อฐานข้อมูล ระบบเดิมใช้ Neo4j Secrets เดิม
ระบบเดิมใช้ความเป็นเพื่อนและการเลือก ส่วนโน้ตบุ๊กแนบใช้ความชอบ LIKES ไม่ได้เปลี่ยนแบบจำลองฐานข้อมูลของระบบเดิม

## วิธีนำไปใช้

1. แตก ZIP แล้วนำไฟล์ภายในโฟลเดอร์ Motorcycle ไปแทนที่ไฟล์ใน repository เดิม รวมไฟล์ใหม่ทั้งหมด
2. เก็บ Neo4j Secrets เดิมใน Streamlit Cloud ไว้ ไม่ต้องตั้งฐานข้อมูลใหม่
3. Main file path ใช้ app.py ตามเดิม จากนั้น commit / push เพื่ออัปเดตเว็บ

รันในเครื่อง:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

ไม่ต้องเพิ่ม Colab URL ใน Secrets ปุ่มเปิดระบบสองการ์ดแรกจะเปิด Google Colab โดยตรง
หากต้องการเปลี่ยนลิงก์ภายหลัง สามารถแก้ default_urls ใน hub_page.py หรือกำหนด STRUCTURE_COLAB_URL และ ANALYSIS_COLAB_URL ใน Secrets ก่อนหัวข้อ [neo4j]
