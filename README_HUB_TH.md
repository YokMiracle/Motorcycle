# หน้ารวมการบ้าน Streamlit

ใช้ app.py เป็นไฟล์หลัก มีการ์ด 4 ใบในรูปแบบ 4 ใบในแถวเดียวบนหน้าจอคอม ความสูงเท่ากัน:

1. ระบบชมรม Neo4j — เปิดไฟล์ GitHub หรือดาวน์โหลด PDF
2. มอเตอร์ไซค์ด้วย Graph — เปิด Colab หรือไฟล์ GitHub
3. มอเตอร์ไซค์ด้วย Neo4j — เปิด Colab หรือไฟล์ GitHub
4. ระบบแนะนำมอเตอร์ไซค์ — เปิดหน้าระบบเดิมภายใน Streamlit

ไฟล์การบ้านอยู่ใน homework/ ต้องอัปโหลดโฟลเดอร์นี้พร้อม hub_page.py
ลิงก์ Colab เปิดไฟล์ที่เก็บใน GitHub โดยตรง

รัน: python -m streamlit run app.py
Streamlit Cloud: Main file path = app.py และใช้ Neo4j Secrets เดิม
