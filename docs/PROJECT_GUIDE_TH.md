# Motorcycle Recommender — 664245008

ระบบ Streamlit + Neo4j ใช้ข้อมูลจาก Notebook ที่แนบ: ผู้ใช้ 10 คน รถมอเตอร์ไซค์ 10 รุ่น ความชอบ 21 คู่

## วิธีรัน
```bash
pip install -r requirements.txt
streamlit run app.py
```
สร้าง `.streamlit/secrets.toml` โดยคัดลอกจาก `.streamlit/secrets.toml.example` แล้วใส่ URI, username, password และ database ของคุณ (Aura ปกติชื่อ neo4j) ห้ามเผยแพร่ secrets

เปิดหน้า **ตั้งค่า / รูปภาพ** แล้วกด **สร้างข้อมูลตัวอย่าง** จากนั้นไปหน้า **รถที่แนะนำ** เลือกผู้ใช้

## ภาพรถ
แนบภาพทั้ง 10 รุ่นที่ผู้ใช้ส่งมาไว้ใน data.json และ assets แล้ว แสดงภาพได้ทันทีหลังสร้างข้อมูล อัปโหลด JPG/PNG/WebP หรือใส่ URL https ของภาพโดยตรงในหน้าตั้งค่า ภาพอัปโหลดถูกย่อและเก็บเป็น base64 ใน Motorcycle.image_data ส่วน URL เก็บใน image_url ภาพจะปรากฏในคำแนะนำ การค้นหา และรายการที่ชอบ ไม่จำเป็นต้องพึ่งไฟล์ในเครื่องเซิร์ฟเวอร์ ภาพจริงต้องเพิ่มเองตามแต่ละรุ่น

## การแนะนำ
ใช้ (User)-[:LIKES]->(Motorcycle) และนับเส้นทางจากผู้ใช้ผ่านรุ่นที่ชอบไปยังผู้ใช้อื่นและรถที่เขาชอบ ตัดรถที่ผู้ใช้ชอบแล้ว คะแนนเท่ากันเรียงชื่อรุ่น ไม่มีสูตรยืมหนังสือ/เพื่อน/คะแนนดาวเดิม
Mint ได้ Kawasaki Ninja 400, Suzuki GSX-R150, Vespa Primavera อย่างละ 1 คะแนนเมื่อใช้ข้อมูลเริ่มต้น

สร้างข้อมูลใช้ MERGE ไม่ลบ Book/Student เดิมในฐานข้อมูล แต่แอปอ่านเฉพาะ User/Motorcycle ของชุดข้อมูลนี้ การสร้างข้อมูลซ้ำจะเพิ่มความชอบเริ่มต้นกลับมา ภาพที่บันทึกไว้ยังอยู่

การบันทึกความชอบปรับข้อมูลจริงและเปลี่ยนคำแนะนำทันที ผู้ใช้ที่ไม่มีเส้นทางร่วมจะไม่มีคำแนะนำ
